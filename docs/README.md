# 🛒 Telegram-магазин — бот для продажи товаров

Это телеграм-бот, который работает как полноценный магазин с интеграцией витрины в Telegram-канале.
Покупатели просматривают товары, листают галерею, заказывают из канала или бота в 1 клик,
добавляют в корзину и оформляют заказ с доставкой.
Администратор управляет наличием, карточками в канале и каталогом прямо из Telegram.

---

## 🚀 Как запустить бота (пошагово)

### 1. Получить токен бота
Откройте Telegram, найдите бота **@BotFather** и напишите ему `/newbot`.
Скопируйте полученный токен.

### 2. Узнать свой Telegram ID
Найдите бота **@userinfobot** и нажмите `/start` — он покажет ваш числовой ID (например, `688585894`).

### 3. Настроить файл `.env`
В корне проекта создайте или отредактируйте `.env`:

```env
TELEGRAM_BOT_TOKEN=вставьте_токен_от_BotFather
ADMIN_IDS=ваш_числовой_ID
ADMIN_PASSWORD=любой_пароль_для_админки
CHANNEL_ID=@your_shop_channel       # Юзернейм или ID канала магазина
AUTO_DELETE_OUT_OF_STOCK_DAYS=7     # Срок удаления из канала (по умолчанию 7)
CURRENCY=UZS
```

> ⚠️ **CHANNEL_ID**: бот должен быть добавлен в канал в качестве администратора с правами публикации, редактирования и удаления сообщений.

### 4. Установить зависимости

#### macOS / Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

#### Windows (PowerShell):
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
# Если PowerShell блокирует скрипты: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
pip install -r requirements.txt
```

#### Windows (Командная строка CMD):
```cmd
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
```

### 5. Заполнить магазин демо-товарами с фото (автосидинг)

Для наполнения каталога одежды качественными фотографиями и публикацией в канал:

- **macOS / Linux**:
  ```bash
  python scripts/seed_demo_with_images.py
  ```
- **Windows**:
  ```cmd
  python scripts\seed_demo_with_images.py
  ```

Или быстрый сидинг без загрузки картинок:
- **macOS / Linux**: `python scripts/seed_demo.py`
- **Windows**: `python scripts\seed_demo.py`

### 6. Запустить бота

```bash
python bot.py
```

### 7. Очистка устаревших постов из канала (Cron)

- **macOS / Linux**:
  ```bash
  python scripts/cleanup_channel.py
  ```
- **Windows**:
  ```cmd
  python scripts\cleanup_channel.py
  ```
Удаляет из канала карточки товаров, которых нет в наличии более `AUTO_DELETE_OUT_OF_STOCK_DAYS` дней (по умолчанию 7).

## 🛍 Возможности для покупателя

- **Витрина в канале**: карточка товара с артикулом (`#P0042`), фото и кнопкой `[🛒 Заказать]`.
- **Deep Linking**: при нажатии кнопки в канале открывается карточка в боте с кнопками `[➕ В корзину]` и `[⚡ Оформить сразу]`.
- **Поиск по ID**: отправка `42`, `#42`, `#P0042` сразу открывает карточку товара.
- **Поиск по названию**: полнотекстовый поиск среди доступных товаров.
- **Категории и пагинация**: перелистывание товаров кнопками `« Назад | Вперед »`.
- **Мультиязычность**: поддержка русского, узбекского и английского языков.

---

## 🔐 Возможности администратора

- **Авторизация**: защищенный паролем доступ по кнопке `🔐 Админ`.
- **Пошаговый мастер добавления товаров**:
  1. Название
  2. Выбор категории инлайн-кнопками или ввод новой
  3. Описание (`/skip`)
  4. Цена
  5. От 1 до 5 фотографий с инлайн-счетчиком и кнопкой `[Готово]`
  6. Предпросмотр перед публикацией в канал или сохранением в боте
- **Управление карточкой товара в один клик**:
  - `[🔄 Наличие: В наличии / Нет]` (моментальное переключение статуса и обновление поста в канале с плашкой `❌ НЕТ В НАЛИЧИИ`)
  - `[✏️ Редактировать]`
  - `[📢 Опубликовать в канал]` / `[🗑 Удалить из канала]`
  - `[❌ Удалить полностью]` (с подтверждением)
- **Управление заказами**: смена статусов (`new`, `processing`, `completed`, `cancelled`).
