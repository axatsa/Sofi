# Техническое описание: Витрина в Telegram-канале + CRUD товаров + Автосидинг

Документ описывает логику интеграции магазина с Telegram-каналом, управление наличием, работу с медиа и автоматическое наполнение демо-данными.

---

## 1. Архитектура базы данных

### Изменения в таблицах

#### 1. Таблица `products` (дополнение полей)
| Поле | Тип | Описание |
|---|---|---|
| `is_available` | INTEGER (0 или 1) | По умолчанию `1`. Флаг наличия товара |
| `out_of_stock_at` | DATETIME / TEXT | Дата и время установки статуса «нет в наличии» (для таймера 7 дней) |
| `channel_message_ids` | TEXT | JSON-массив ID сообщений в канале (например `"[1042]"` или `"[1042, 1043]"` при альбоме) |
| `created_at` | DATETIME | Дата добавления товара |
| `updated_at` | DATETIME | Дата последнего изменения |

#### 2. Новая таблица `product_photos` (поддержка от 1 до 5 фото)
Вместо одного поля `photo_file_id` в таблице `products` создается отдельная таблица для галереи:
```sql
CREATE TABLE IF NOT EXISTS product_photos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id INTEGER NOT NULL REFERENCES products(id) ON DELETE CASCADE,
    file_id TEXT NOT NULL,
    position INTEGER NOT NULL DEFAULT 0
);
```

## 2. Специфика Telegram Bot API: Карточка товара в канале

> ⚠️ **Критическое техническое ограничение Telegram Bot API**:
> Метод `sendMediaGroup` (отправка альбома из 2–5 фото) **не поддерживает** `reply_markup` (инлайн-кнопки). Инлайн-кнопку под фото можно прикрепить **только** к одиночному фото (`sendPhoto`).

### Решение для карточки товара:
* **Вариант А (1 фото)**: Отправляется `sendPhoto` с полным описанием в `caption` и инлайн-кнопкой `[🛒 Заказать]`.
* **Вариант Б (2–5 фото)**: 
  1. Бот отправляет альбом через `sendMediaGroup` (описание прикрепляется к первому фото).
  2. Следом бот отправляет сервисное сообщение с текстом `«Для заказа товара нажмите кнопку ниже ⬇️»` и инлайн-кнопкой `[🛒 Заказать]`.
  3. В `channel_message_ids` сохраняются ID всех сообщений альбома + ID сообщения с кнопкой, чтобы при удалении стирать пост целиком.

### Формат карточки в канале:
```text
🧥 Пуховик зимний
Артикул / ID: #P0042

Тёплый зимний пуховик, водоотталкивающая ткань.
💰 Цена: 890 000 UZS

[🛒 Заказать] 
```
*Кнопка «Заказать» содержит URL:* `https://t.me/<BOT_USERNAME>?start=order_42`

## 3. Deep Linking (Переход из канала в бот)

1. Покупатель жмет кнопку **«Заказать»** в канале.
2. Открывается диалог с ботом с параметром `/start order_42`.
3. Обработчик `start` парсит префикс `order_`:
   - Находит товар `ID=42`.
   - Если товар в наличии: выводит карточку товара в боте с кнопками `[➕ В корзину]` и `[⚡ Оформить сразу]`.
   - Если товар закончился: выводит сообщение `«К сожалению, этот товар уже раскуплен»` и предлагает посмотреть другие товары из этой категории. Подписок и лишних уведомлений нет.

## 4. Логика наличия и удаление из канала через Cron

```
[Админ: переключает "Нет в наличии"]
          │
          ▼
1. Обновление статуса в БД: is_available = 0, out_of_stock_at = NOW()
2. Немедленное редактирование поста в канале:
   - В заголовок добавляется плашка: "❌ НЕТ В НАЛИЧИИ"
   - Кнопка "Заказать" убирается из сообщения
          │
          ▼
[Cron-скрипт: cleanup_channel.py (запуск раз в сутки / час)]
          │
          ├── Находит товары: is_available = 0 AND out_of_stock_at <= NOW() - 7 days
          │   AND channel_message_ids IS NOT NULL
          │
          └── Удаляет сообщения из канала через bot.delete_message()
              Очищает поле в БД: channel_message_ids = NULL
              Сам товар в базе данных и каталоге админа СОХРАНЯЕТСЯ.
```

### Возврат в наличие:
Если админ в боте снова нажимает «В наличии»:
- `is_available = 1`, `out_of_stock_at = NULL`.
- Если пост еще висит в канале (< 7 дней): бот убирает плашку `❌ НЕТ В НАЛИЧИИ` и возвращает кнопку заказа.
- Если пост уже был удален из канала (> 7 дней): бот публикует карточку заново и сохраняет новые `channel_message_ids`.

## 5. CRUD товаров через бота для админа

### Добавление товара (FSM / пошаговый мастер):
1. **Название**: Текстовое сообщение.
2. **Категория**: Выбор инлайн-кнопкой из существующих или ввод новой.
3. **Описание**: Текст или `/skip`.
4. **Цена**: Числовое значение в UZS.
5. **Фотографии (1–5 шт)**:
   - Админ отправляет фото (по одному или альбомом).
   - Бот выводит счетчик: `«Получено фото: 2/5. Отправьте еще или нажмите [Готово]»`.
   - Кнопка `[Готово]` завершает загрузку фото.
6. **Обязательный предпросмотр (Preview)**:
   - Бот присылает админу карточку в том виде, в котором она пойдет в канал.
   - Под карточкой кнопки:
     - `[📢 Опубликовать в канал]` (публикует пост, сохраняет message IDs)
     - `[💾 Сохранить только в боте]` (товар доступен только в боте без канала)
     - `[✏️ Изменить]` / `[❌ Отмена]`

### Управление товаром (Инлайн-меню админа):
Под каждым товаром в списке админа доступны кнопки:
- `[🔄 Наличие: В наличии / Нет]` (быстрое переключение в один клик)
- `[✏️ Редактировать]` (цена, текст, фото)
- `[📢 Опубликовать в канал]` (если еще не опубликован)
- `[🗑 Удалить из канала]` (удаляет только пост в Telegram, товар в БД остается)
- `[❌ Удалить полностью]` (удаляет товар из базы данных и пост из канала с подтверждением)

## 6. Каталог и поиск для покупателя в боте

1. **Поиск по ID товара**:
   - Покупатель видит в канале `#P0042` и может отправить боту `42` или `#42` — бот сразу откроет карточку.
2. **Поиск по названию**:
   - Полнотекстовый поиск по подстроке (`LIKE %запрос%`).
3. **Навигация по категориям**:
   - Меню категорий с отображением только тех товаров, которые есть в наличии (`is_available = 1`).
   - Пагинация кнопками `« Назад | Вперед »`.

## 7. Скрипт автоматического наполнения (`seed_demo_with_images.py`)

### Задача скрипта:
Взять демо-список одежды, автоматически найти релевантную фотографию высокого качества без платных API-ключей, загрузить в базу и отправить в канал.

### Источники бесплатных изображений без авторизации:
1. **Unsplash Source / Direct Keywords**: 
   Прямые запросы по ключевым словам вида:
   `https://images.unsplash.com/photo-...?auto=format&fit=crop&w=800&q=80`
   или бесплатный поиск через DuckDuckGo Images / Wikimedia API.
2. **Локальный кэш / скачивание**:
   - Скрипт по ключевому слову (например, `trench coat beige`, `sneakers white`, `leather jacket`) скачивает картинку во временный файл.
   - Отправляет файл через Bot API в канал.
   - Полученный `file_id` Telegram сохраняет в таблицу `product_photos`.
   - Временный файл удаляется.
   - Никаких битых внешних ссылок — всё хранится на серверах Telegram через `file_id`.

## 8. Необходимые переменные в `.env`

```env
TELEGRAM_BOT_TOKEN=...
ADMIN_IDS=...
ADMIN_PASSWORD=...
CHANNEL_ID=@your_shop_channel       # Юзернейм или цифровой ID публичного канала
CURRENCY=UZS
DATABASE_PATH=shop.sqlite3
AUTO_DELETE_OUT_OF_STOCK_DAYS=7     # Срок удаления из канала (по умолчанию 7)
```
*Бот обязательно должен быть добавлен в канал в качестве администратора с правами на публикацию, редактирование и удаление сообщений.*
